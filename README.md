# VitebskStay — архитектурные «жемчужины» Витебска

Лендинг о достопримечательностях Витебска: популярные маршруты с ценами, фотогалерея и форма записи на экскурсию.

## Обоснование выбора темы

Витебск — культурная столица Беларуси с богатым архитектурным наследием (храмы, исторические здания, пешеходные маршруты), при этом город редко представлен в виде современного туристического сервиса. Тема позволяет показать на реальном контенте все требуемые элементы: карточки с фотографиями и ценами, галерею изображений и форму обратной связи.

## Структура проекта

```
it-reit-2026/
├── index.html      — единственная страница сайта
├── styles.css      — все стили проекта
├── script.js       — вся логика: слайдер и модальное окно
├── img/            — изображения (фото города и маршрутов)
└── README.md       — документация проекта
```

## Запуск

Открыть `index.html` в браузере.

## Технологии и библиотеки

- **HTML5** — семантическая разметка (`header`, `nav`, `section`, `footer`, `form`);
- **CSS3** — Flexbox, `position: relative/absolute`, `aspect-ratio`, `object-fit`, CSS-переменные, медиазапросы, нативный nesting (`&:hover`);
- **JavaScript (ES6)** — без библиотек и фреймворков: `querySelector`, `addEventListener`, `classList`, шаблонные строки;
- **Google Fonts** — шрифт Poppins (единственная внешняя зависимость);
- валидация формы — нативная браузерная (`required`, `type="email"`, `pattern`).

## Интерактивные элементы

- **Слайдер фотогалереи** — лента слайдов во «вьюпорте» с `overflow: hidden`; JS сдвигает ленту через `transform: translateX()`, плавность даёт `transition` в CSS. Управление: стрелки по бокам и точки-пагинация (генерируются скриптом по количеству слайдов), листание зациклено.
- **Модальное окно записи** — открывается по кнопке «Записаться» в шапке: имя, email с валидацией и выбор маршрута из списка. Закрытие — крестиком, кликом по фону или клавишей Esc. После отправки показывается подтверждение.
- **Hover-эффекты** — кнопки, пункты меню и ссылки реагируют на наведение.

## Адаптивность

Брейкпоинт `max-width: 768px`: шапка перестраивается в две строки, hero и карточки становятся колонкой, слайдер и модальное окно занимают всю ширину экрана.

## Дизайн-система

- `html { font-size: 62.5% }` → `1rem = 10px`, все размеры в rem;
- цвета: `--primary: #3252DF` (фирменный синий), `--nav-color: #152C5B` (тёмно-синий текст);
- скругления: 1rem (кнопки, плашки), 2.5rem (карточки, слайдер, модалка).
