# VitebskStay

Тема: ”Архитектурные жемчужины Витебска“

Лендинг об архитектурных достопримечательностях Витебска: популярные маршруты с ценами, фотогалерея и форма записи на экскурсию.

Учебный проект на чистых HTML + CSS + JS, без фреймворков и сборки.

## Запуск

Открыть `index.html`.

## Что на странице

- **Шапка** — логотип VitebskStay. (двухцветный, через `span`-акцент), меню, кнопка «Записаться».
- **Hero** — заголовок, подзаголовок, кнопка, статистика, фото города справа.
- **Маршруты** — 6 карточек с фото. Цена и название — плашки, спозиционированные `absolute` внутри карточки с `position: relative`.
- **Слайдер** — лента слайдов во «вьюпорте» с `overflow: hidden`; JS двигает ленту через `transform: translateX()`, плавность даёт `transition` в CSS. Стрелки, точки-пагинация (генерируются автоматически), листание зациклено.
- **Модалка записи** — форма с именем, email и выбором маршрута. Валидация email браузера.
- **Подвал** — слоган и копирайт.

## Дизайн-система

- **Сетка размеров:** `html { font-size: 62.5% }` → `1rem = 10px`, все размеры в rem.
- **Цвета (CSS-переменные в `:root`):**
  - `--primary: #3252DF` — фирменный синий (кнопки, плашки, акценты);
  - `--nav-color: #152C5B` — тёмно-синий (текст, заголовки).
- **Шрифт:** Poppins (Google Fonts), 400/500.
- **Скругления:** 1rem для кнопок и плашек, 2.5rem для карточек и слайдера.

## Приёмы, которые здесь используются

- Flexbox-раскладка (`justify-content`, `align-items`, `gap`);
- связка `position: relative` + `absolute` для плашек, стрелок и крестика;
- `aspect-ratio` для сохранения пропорций фото в слайдере;
- `object-fit: cover` для картинок;
- вложенные правила CSS (`&:hover`) — нативный CSS nesting;
- базовый JS: `querySelector`, `addEventListener`, `classList`, работа с формой.
